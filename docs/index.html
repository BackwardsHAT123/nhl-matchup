Simulated joint outcomes for 2–3 leg parlays, ranked by correlation lift = P(all legs hit) ÷ product of each leg's probability. Fair odds are the break-even price: if your book pays better than fair odds the parlay is +EV by this model. Type your book's SGP price to see EV. Books already discount for correlation, so check that price, not just the lift. Plays pairing a player's shots with the opposing goalie's saves are excluded (same shots counted twice).

Method

Score = 75% xGF% differential + 15% starting-goalie GSAx differential + 10% schedule (back-to-back, rest days), each scaled to a common spread; a logistic curve turns it into win probability (home ice in the intercept). Fit on earlier seasons only. Data: MoneyPuck and the NHL API, refreshed daily by GitHub Actions. Win-prediction model only — it does not use betting odds, so it does not by itself show an edge over the market. Not financial advice.
